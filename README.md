# Mon site web Simple
Ce dépôt contient un exemple simple de site web personnel avec des
fichiers HTML, CSS et JavaScript basiques.
## Contenu
- `index.html`: La structure principale de la page web.
- `style.css`: Les styles visuels pour le site.
- `script.js`: Un petit script interactif (alerte au clic sur un
bouton).
- `README.md`: Ce fichier, décrivant le projet.
## Comment l'utiliser
1. Clonez ce dépôt sur votre machine locale.
 `git clone https://github.com/votre-pseudo/mon-site-web-simple.git`
2. Ouvrir le fichier `index.html` dans votre navigateur web.
---
**Objectif pédagogique**
Ce projet sert d'exemple pour découvrir Git et GitHub,
notamment les opérations de clonage, de commit, de push,
de pull et de gestion des branches.
